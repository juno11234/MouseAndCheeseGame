## 1. 기능 요약

URP(PC 렌더러, `PC_Renderer.asset`) 기준으로 HLSL 커스텀 툰 셰이더(`Custom/ToonLit`)를 새로 작성하고, 쥐/고양이 캐릭터 머티리얼(`Rat_Mat`, `Cat_Mat`)과 부엌 환경 머티리얼 5종(`Oven_Mat`, `Sink_Mat`, `Table&Chair_Mat`, `Wall_Mat`, `refrigerator_Mat`) 총 7개에 적용했다. 외곽선은 오브젝트별 Pass(Inverted Hull) 방식이 아니라, URP 내장 `FullScreenPassRendererFeature` + 커스텀 화면공간(Depth/Normal Edge Detection) 셰이더(`Custom/ToonOutlineFullScreen`) 조합으로 씬 전체에 한 번 적용되며, `DepthNormals` Pass를 가진 셰이더를 쓰는 모든 오브젝트(현재+향후 추가분)에 별도 설정 없이 자동 적용된다.

- N-step(2단계) 라이팅 밴딩: `smoothstep`으로 밝음/그림자 경계를 양자화.
- 림 라이트: 시야 방향 기준 실루엣 가장자리를 밝게 강조(그림자 영역에는 가산하지 않음).
- 외곽선: 화면 전체 포스트프로세스(Roberts Cross depth/normal edge detection), 씬의 모든 `Custom/ToonLit` 오브젝트에 공통 적용.
- Additional Light, Specular Highlight는 이번 범위에서 제외(메인 Directional Light만 지원).
- Mobile 렌더러(`Mobile_Renderer.asset`)는 이번 범위에서 다루지 않음.

## 3. 구현 방식 (Unity Editor 연동 작업)

`.mat`/`.asset` 파일은 Unity YAML이라 텍스트 편집기로 직접 고치면 guid/fileID 참조가 깨질 위험이 있어, 아래 작업은 전부 연결된 Unity Editor(에디터 실행 중, 포트 7801)에 C# 코드를 `unity command eval_file`로 실행해 처리했다(Inspector 수작업과 동일한 결과, 재현 가능).

1. 7개 머티리얼: `AssetDatabase.LoadAssetAtPath<Material>(...)`로 로드 → 기존 `_BaseMap` 텍스처 참조를 미리 저장 → `material.shader = Shader.Find("Custom/ToonLit")` → 저장해둔 텍스처를 `SetTexture("_BaseMap", ...)`로 재확인 적용 → `AssetDatabase.SaveAssets()`.
2. `ToonOutline_Mat.mat`: `new Material(Shader.Find("Custom/ToonOutlineFullScreen"))` 후 `AssetDatabase.CreateAsset`.
3. `PC_Renderer.asset`(`UniversalRendererData`): URP 에디터 소스(`ScriptableRendererDataEditor.AddComponent()`)와 동일한 절차 — `FullScreenPassRendererFeature` 인스턴스를 `ScriptableObject.CreateInstance`로 생성 → `AssetDatabase.AddObjectToAsset`로 서브에셋 등록 → `SerializedObject`로 `m_RendererFeatures`/`m_RendererFeatureMap` 배열에 추가 → `ApplyModifiedProperties()` → `AssetDatabase.SaveAssetIfDirty` + `ImportAsset`.

## 4. 컴파일/렌더링 확인 결과

- `unity command eval_file`로 `ShaderUtil.ShaderHasError()` / `ShaderUtil.GetShaderMessages()`를 호출해 `Custom/ToonLit`, `Custom/ToonOutlineFullScreen` 두 셰이더 모두 `hasError=False`, 메시지 없음을 확인했다.
- 최초 작성 시 `ToonOutlineFullScreen.shader`에서 `#include` 순서 문제(`Blit.hlsl`을 URP `Core.hlsl`보다 먼저 include)로 `unrecognized identifier 'TEXTURE2D_X'` 컴파일 에러가 발생했다. URP 자체 `Shaders/Utils/CoreBlit.shader`의 include 순서(`Core.hlsl` → `Blit.hlsl`)를 참고해 순서를 바로잡아 해결했다(9절 예상대로 URP 버전별 확인이 실제로 필요했던 부분).
- `unity command get_console_logs`로 확인한 결과 머티리얼 교체/Renderer Feature 등록 작업 중 에러/경고 로그는 없었다.
- `unity command capture_game_view`로 Play 모드 화면을 캡처해 육안 확인한 결과: 쥐 캐릭터(귀/몸)에 밝음/그림자 2단계 밴딩이 뚜렷하게 나타나고, 벽·오븐·테이블·캐릭터 실루엣 등 씬 전체 오브젝트 경계에 검정 외곽선이 고르게 표시됨을 확인했다(새 Renderer Feature가 SSAO와 함께 정상 동작).

## 5. 남은 확인/튜닝이 필요한 부분 (사용자 육안 확인 권장)

1. `_ShadowColor`/`_ShadowThreshold`/`_ShadowSmoothness`, `_RimColor`/`_RimThreshold`/`_RimSmoothness` 값은 7개 머티리얼 모두 셰이더 Properties 기본값(계획 문서 7-1절 수치) 그대로 두었다. 씬 조명(Directional Light 각도/색상)에 맞춰 각 머티리얼 Inspector에서 미세 조정이 필요할 수 있다.
2. `ToonOutline_Mat.mat`의 `_DepthThreshold`(0.01)/`_NormalThreshold`(0.4)는 초기값이다. Roberts Cross는 원시(raw, non-linear) 깊이값을 그대로 비교하는 방식이라 카메라와의 거리에 따라 민감도가 달라질 수 있으므로(계획 9-2절 근거), Directional Light를 돌려가며 실제 씬 스케일에 맞게 값을 조정하는 과정이 필요하다.
3. `FullScreenPassRendererFeature.injectionPoint`는 기본값(`AfterRenderingPostProcessing`)으로 두었다. Bloom/Tonemapping 등 포스트프로세스가 추가되면 외곽선이 그 위에 그대로 덮이므로, 원하는 시각 결과에 따라 `BeforeRenderingPostProcessing`으로 바꿔야 할 수도 있다(Inspector에서 `PC_Renderer.asset` 선택 → Renderer Feature 항목에서 변경).
4. Additional Light(포인트/스팟 조명)를 추가할 계획이 있다면 `ToonLitForwardPass.hlsl`의 `ToonFragment()`에 `GetAdditionalLightsCount()`/`GetAdditionalLight()` 루프를 추가하는 확장 작업이 별도로 필요하다(계획 9-3절 근거, 현재 미구현).
5. `Mobile_Renderer.asset`/`Mobile_RPAsset.asset`은 이번 작업 범위에서 완전히 제외했다. 모바일 빌드에서 같은 룩을 원한다면 별도 계획/검토가 필요하다.

## 6. 테스트 방법

1. Unity Editor에서 `SampleScene`을 Play 모드로 실행한다.
2. 쥐/고양이 캐릭터와 부엌 오브젝트(오븐, 싱크대, 테이블/의자, 냉장고, 벽)에 밝음/그림자 2단계 밴딩이 적용되어 있는지, 텍스처가 정상적으로 보이는지 확인한다.
3. Directional Light를 회전시키며 밴딩 경계와 림 라이트가 방향에 맞춰 자연스럽게 움직이는지 확인한다.
4. 씬의 모든 오브젝트 경계(캐릭터 실루엣 포함)에 검정 외곽선이 나타나는지 확인한다. 새 오브젝트를 추가할 때 `Custom/ToonLit` 계열 셰이더를 사용하는지만 확인하면 별도 Renderer Feature 설정 없이 외곽선이 자동 적용된다.
5. SSAO(`PC_Renderer.asset`의 `ScreenSpaceAmbientOcclusion` Feature)가 기존처럼 정상 작동하는지(오브젝트 접촉부 음영) 확인한다.
6. `Assets/Settings/PC_Renderer.asset`을 Inspector에서 선택해 Renderer Feature 목록에 `Screen Space Ambient Occlusion`과 `Full Screen Pass Renderer Feature` 2개가 모두 등록되어 있는지, 후자의 `Requirements`가 Depth+Normal, `Pass Material`이 `ToonOutline_Mat`인지 육안으로 재확인한다.
