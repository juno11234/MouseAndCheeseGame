# 기획 의도 / 작업 페이지 구조화 요약

- 작성 날짜: 2026-09-11 (26_0911)
- 목적: Notion에서 "기획 의도"와 "작업 페이지"를 분리하는 작업 내용을 새 대화 섹션에서도 이어갈 수 있도록 요약 보관

## 1. 배경

기존에는 Notion "기획 의도" 하위 시스템 페이지(고양이 AI, 배고픔·속도 스탯 등)에 왜(기획 의도)와 어떻게(구현 방식/규칙/구현요소 등)가 섞여 있었다. 이를 역할별로 분리했다.

- **기획 의도**: "왜 이 시스템이 필요한가"만 남긴다.
- **작업 페이지**: "어떻게 구현하는가"를 System → Feature → Task 3단 구조로 담는다.
  - System: 시스템 단위 (예: 고양이 AI)
  - Feature: 시스템 내부의 기능 단위 (예: 추격 갭 시스템)
  - Task: 상세한 구현 내용 (예: 갭 0 도달 시 게임오버 처리)

## 3. 작업 페이지에 새로 채운 내용 (System → Feature → Task)

1. **고양이 AI**
   - 플레이어 경로 기록 → 위치/회전 기록 버퍼(0.1초 간격), 가구 등반 등 특수 동작 이벤트 기록
   - 고양이 경로 추종 컨트롤러 → 기록된 경로 재생 이동 컨트롤러, 가구 등반 시 애니메이션 트리거
   - 추격 갭 시스템 → 갭 계산 로직, 갭↔배고픔 매핑 곡선(밸런싱 필요), 갭 0 도달 시 게임오버 처리
2. **배고픔·속도 스탯**
   - 배고픔 게이지 코어 로직 → 시간 경과 지속 감소, 치즈 섭취 시 고정량 회복
   - 배고픔→이동속도 매핑 → 수치 변환(밸런싱 값: 초당 감소량/치즈 회복량/최저·최고 속도 캡), 배고픔 0 도달 시 최저속도 전환(즉사 아님)
3. **속도 이펙트**
   - 카메라 연출 → 속도 비례 FOV 확대, 모션 블러/화면 가장자리 블러
   - 환경 연출 → 바람 파티클·배경 패럴럭스 속도 연동
   - 위험 경고 연출 → 저속 진입 시 붉은 비네트, (선택) 배경음 피치업/바람소리 볼륨
4. **치즈·장애물 랜덤 생성**
   - 절차적 패턴 생성 → 랜덤 조합 알고리즘(맵 암기 방지), 기획자 테스트/밸런싱용 패턴 테이블 데이터 구조
   - 치즈·장애물 스폰 → 테이블 기반 스폰 로직
5. **점수·랭킹 시스템**
   - 점수 계산 → 주행거리+치즈 보너스 공식
   - 로컬 기록 저장 → PlayerPrefs 기반 저장/불러오기(서버 연동 없음)
   - 결과 UI → 게임오버 화면 이번 판 점수+최고기록 표시

System 5개, Feature 13개, Task 22개 모두 Notion에 생성 완료. 모든 System/Task의 날짜는 2026-09-11, System 상태는 전부 "시작 전"으로 시작한다.
